## קוד התיקונים

ה־patch המצורף כולל את הקוד המלא שנוסף או השתנה בכל קובץ. אלו שלוש דוגמאות מתוך המימוש הנוכחי.

### איתור מקטע נוסף בסוף הסעיף

```ts
const first = Array.from({ length: Math.max(old.length, next.length) }, (_, index) => index)
  .find((index) => compact(stripSection(old[index]?.body || "")) !==
    compact(stripSection(next[index]?.body || ""))) ?? 0;
```

חלון הממצא מתחיל בהבדל, וכל יתר מקטעי הסעיף נשמרים. סדר ההצגה נשמר במסד בעמודת `sources.position`.

### שימור תוצאה ללא שינוי

```ts
const unchanged = sections.filter((section) =>
  makeCandidates([section], older, newer, rankedOld, rankedNew).length === 0);
```

המערכת משתמשת באותה לוגיקת התאמה גם להחלטה שסעיף נבדק ולא השתנה, ושומרת את המערך בטרנזקציה של ההשוואה.

### דחיית שתי הצעות מודל לאותה שורה

```ts
const matchesForRow = proposals.filter((item) => item.row === row);
if (matchesForRow.length !== 1 || candidate.kind !== "changed") return candidate;
```

בהמשך נבדקים כל מזהי המקורות, ללא כפילויות, נגד המקטעים שנבחרו בפועל לכל צד.

## החלטות ארכיטקטורה ושימור נתונים

- השרת נשאר בתוך Next.js, ו־Python משמש לחילוץ ולתצוגת PDF. לא נוסף שרת API נוסף.
- מיגרציות 004, 005 ו־006 מוסיפות סדר מקורות, סימון שלמות הקשר ותיעוד סעיפים ללא שינוי. הן רצות בטרנזקציה תחת נעילת המיגרציות הקיימת.
- מסמכים, גרסאות והשוואות קיימים נשמרים. הסברי AI היסטוריים חלקיים מסומנים להרצה מחדש.
- הקליטה ממשיכה להשתמש ב־SHA-256, נעילה על פוליסה, אילוצי ייחוד, lease ו־claim. המקורות ממשיכים להיאכף במסד באמצעות מפתחות זרים הכוללים גרסה ומספר עמוד.
- המודל נשאר Nemotron החינמי דרך OpenRouter, עם מחירי prompt/completion/request מרביים של אפס וללא ניסיון חוזר אוטומטי.
- סביבת העבודה הנוכחית מיועדת למפעיל מקומי מהימן. לא קיימת מערכת כניסה והרשאות רב־משתמשים. פריסה של סביבת מסמכים פרטיים דורשת את שכבת האימות המתועדת ב־README.
- במצב דמו ציבורי העלאה וקריאות מודל חסומות. אין משאבי ענן חדשים או פרסום ציבורי כחלק מהביקורת.

## גבולות הבדיקה

הבדיקות המקומיות השתמשו ב־PGlite עם pgvector. Docker ו־PostgreSQL חיצוני לא היו זמינים להרצת אינטגרציה כאן. ענף `pg` עבר בדיקה סטטית וטיפוסים, אך תקלת רשת אמיתית מול PostgreSQL חיצוני עדיין דורשת בדיקה בסביבת הפריסה.

בדיקות timeout ו־429 של ספק המודל משתמשות בתגובה מדומה. בדיקת ClauseLens האמיתית הייתה בדיקת עשן על שאלת דמו אחת. היא אינה מדידת איכות של המודל על כל 30 השאלות. גם מסמך שמנסה לתת הוראות נבדק בחילוץ ובאימות מקורות, ולא כמבחן שמוכיח עמידות אוניברסלית לכל ניסוח של הזרקת הוראות.

הקורפוס כולל 30 שאלות על שתי פוליסות פומביות. אין כאן סט נפרד של מסמכים שלא שימשו לפיתוח. מקור נכון אינו מאמת אוטומטית כל מסקנה מילולית של מודל. מגבלות אלו מוצגות גם בגבול המוצר ובמתודולוגיית המדידה.

העבודה המקומית כוללת גם את השינויים מהשלבים הקודמים בפרויקט. הביקורת אינה מבצעת commit, push או פרסום.
